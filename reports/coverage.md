## Ambiguous Otzaria titles

These normalised titles match more than one work in the pack. Otzaria calls
Bavli Berakhot and Mishnah Berakhot by the same name, and normalising
`משנה ברכות` produces the same key again. The plugin therefore **asks** which
book is meant rather than picking one — showing the wrong book's translation
is exactly the failure this project must not have.

| Normalised title | Works it could mean |
|---|---|
| ברכות | Mishnah Berakhot / Berakhot |
| שבת | Mishnah Shabbat / Shabbat |
